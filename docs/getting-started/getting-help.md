# Getting Help

> **Placeholder content.** Outline for review. Verify against sources.

Will cover:

- Making envy talk: `--verbose` for the reasoning narrative, `-q` for warnings
  and errors only.
- `--trace` for machine-readable JSONL event streams, and what to attach to a
  bug report. See [Logging & Tracing](/reference/observability).
- Reading envy output. Human messages go to stderr. stdout is reserved for
  machine-readable results such as `envy product`, `envy package`, `envy hash`,
  and `envy export`.
- Common first-run problems and where the answers live, in
  [Troubleshooting](/reference/troubleshooting).
- Where to file issues, and how to report reproducibly: envy version, manifest,
  trace file.
