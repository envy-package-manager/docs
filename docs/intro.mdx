envy is an unopinionated, serverless, per-project package manager. A project
pins its entire toolchain — compilers, CMake, Python, vendor SDKs — in one Lua
manifest (`envy.lua`) checked into the repo, alongside a committed bootstrap
script that downloads envy itself on first use.

There is no server, no daemon, and no registry. Packages are described by Lua
*specs* that fetch bits from wherever they already live (HTTP, FTP, SMB, Git,
SSH, S3), verify them by SHA-256, and install them into a content-addressed
cache shared by every project on the machine.

Nothing is installed system-wide. A teammate clones the repo, runs
`./tools/envy sync`, and gets a byte-identical toolchain.

```lua title="envy.lua"
-- @envy schema "1"
-- @envy version "0.0.17"
-- @envy bin "bin"

PACKAGES = {
  { spec = "local.cmake@r0", source = "local.cmake@r0.lua",
    options = { version = "4.2.3" } },

  { spec = "local.python@r0", source = "local.python@r0.lua",
    options = { version = "3.13.11", provide_python3 = true } },
}
```
